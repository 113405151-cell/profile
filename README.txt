個人介紹網站｜使用說明

檔案內容
- index.html：網站內容與結構
- style.css：版面、顏色、字體與響應式設計
- script.js：手機版導覽選單互動

快速預覽
1. 解壓縮 ZIP。
2. 直接用瀏覽器開啟 index.html。

上傳網站
- 將 index.html、style.css、script.js 一起上傳到網站主機的同一個資料夾。
- 若使用 GitHub Pages：建立 GitHub repository，將這三個檔案放在根目錄，推送後到 Settings → Pages 開啟部署。
- 若使用 Netlify：可將解壓後的資料夾拖曳到 Netlify 的部署區。

上線前請修改
- 將 [你的名字] 替換成你的姓名或想使用的稱呼。
- 將 Email、Instagram、作品集連結改成自己的資訊。
- 作品與經歷目前是依照個人介紹方向撰寫的範例，請確認內容、年份與參與程度符合實際情況。
- 可在 index.html 中新增照片；目前採用抽象幾何圖形作為視覺主圖。

網站使用 Google Fonts，需連線才能載入指定字體；離線時會使用系統字體替代。
